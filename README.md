# Один герой

Длинные 2D-истории (20–40 мин, 16:9) для YouTube-канала «Один герой». Герой — Марк.

- `STYLE_BIBLE.md` — правила канала: текст, крючок, главы, голос, картинка, монтаж, чек-лист.
- `.claude/skills/odin-geroy-video/` — skill: от идеи до готового ролика (сценарий → ElevenLabs → Remotion → рендер → проверка).
- `style_tests/` — эталон героя (`HERO_sheet.png`) и тестовые кадры стиля; код персонажа — `gen_quake.js`.
- `videos/<NN>_<slug>/` — сценарии и материалы роликов (медиа в git не хранится).
