# Enutt — воксельная труппа для роликов

Шесть воксельных персонажей в одном стиле, с общим скелетом, пиксельными эмоциями и набором плавных анимаций.
Всё собрано кодом на three.js, поэтому любого персонажа можно поставить в любую сцену, в любую позу и снять с любой камеры.

## Анимации (`src/clips.js`)
Все клипы начинаются и заканчиваются в позе покоя, поэтому их можно склеивать подряд без рывков.
`idle` дыхание · `talk` говорит с жестами (рот сам артикулирует) · `wave` машет · `walk` цикл ходьбы ·
`celebrate` прыжок радости · `laugh` смех · `sad` грусть · `angry` злость с топотом · `surprised` удивление ·
`think` рука у подбородка · `point` указывает · `facepalm` · `shrug` пожимает плечами · `yes` кивок · `no` «нет».

Поверх любой позы автоматически добавляются дыхание и моргание.

## Эмоции (`src/faces.js`)
`neutral smile happy laugh sad angry surprised thinking skeptical wink worried bored embarrassed determined`.
Глаза, брови и рот — независимые слои, можно смешивать: `{ emotion: 'happy', mouth: 'o', gaze: [1, 0] }`.
Для липсинка есть виземы рта `A E O U M closed` — их можно подставлять по громкости озвучки (`opts.mouth`).

## Скелет (`src/rig.js`)
`hips → spine → head`, `armL/R → elbowL/R`, `legL/R → kneeL/R → ankleL/R`. Углы в градусах.
Руки: `rx < 0` — вперёд/вверх, `armL rz > 0` / `armR rz < 0` — в сторону. Колени: `rx > 0` — сгиб.
Стопы сами остаются параллельны полу (`plant`).

## Команды
```bash
npm install
npm run render -- --chars max,anya --clips wave,talk   # PNG → WebM с альфа-каналом + MP4-превью
npm run render -- --png                                # сохранить и прозрачные PNG-кадры (renders/frames)
npm run sheets                                         # листы эмоций
npm run viewer                                         # собрать viewer/index.html (интерактивный просмотр)
node scripts/still.mjs out.png '[{"id":"max","clip":"wave","t":1},{"id":"anya","x":30,"face":"laugh"}]' 1920 1080
```

## Готовые файлы
- `renders/video/<персонаж>/<клип>.webm` — 1024×1024, 30 fps, прозрачный фон (VP9 + альфа), для монтажа поверх фона.
- `renders/preview/<персонаж>/<клип>.mp4` — превью на светлом фоне.
- `renders/sheets/` — листы эмоций и общий состав.
