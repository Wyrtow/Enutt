# Голоса канала — ElevenLabs, русский, с эмоциями

## Голоса канала (утверждены — `production/voice.json`)
| Роль | Кто говорит этим голосом | Голос ElevenLabs |
|---|---|---|
| **MALE** | весь рассказ Марка + реплики **всех мужчин** | Pavel — Warm Conversational Narrator |
| **FEMALE** | реплики **всех женщин и девушек** | Kate — Multilingual Storyteller |
| **GIRL** | реплики **всех девочек** | Mila Svetlova + тег `[childlike voice]` |
| **BOY** | реплики **всех мальчиков** | El — Character + тег `[young boy voice]` |
Модель — `eleven_v4`. Детских русских голосов в библиотеке ElevenLabs нет, поэтому детей играют высокие женские голоса с тегом-префиксом (так же делают в русском дубляже).
Голоса берутся только из `production/voice.json` и не меняются между роликами; `prefix_tag` голоса ставится в начало каждой его реплики.
Разные мужчины/женщины одним голосом различаются тегами подачи (`[deep voice]`, `[raspy]`, `[elderly voice]`, `[softly]`), а не сменой голоса.


## Модель
- **`eleven_v3` или `eleven_v4`**: только они понимают **аудио-теги эмоций** в квадратных скобках. Старые модели (`multilingual_v2`, `turbo`, `flash`) читают теги вслух как слова, поэтому для канала они не подходят.
- На первом ролике **сравни v3 и v4 на одном абзаце** (крючок, ~400 символов) одним голосом. Выбор запиши в `production/voice.json` (`voice_id`, `model_id`, дата) и больше не меняй.
- Текст на русском, теги на английском: `[nervous]`, `[whispers]`.
- У v3/v4 нет параметра скорости. Темп задаётся текстом: короткие фразы, многоточия, `[pause]`, `[slowly]`.

## Голос
Мужчина 25–35 лет, русский без акцента, тёплый, слегка хрипловатый, интонация «рассказываю другу», без дикторского пафоса.
1. Сначала `creative_list_voices`: ищи русские мужские голоса для рассказа (narration/storytelling).
2. Если подходящего нет, используй `creative_design_voice`. Описание голоса возьми выше, строку для пробы — первую фразу сценария, язык `ru`. Затем `creative_save_designed_voice`.
3. Дай пользователю послушать 2–3 варианта. Без его «да» голос не фиксируй.

## Теги по типам битов (текст русский, теги английские)
| Бит сюжета | Теги | Пример |
|---|---|---|
| Крючок, первая фраза | `[softly]` → `[dramatically]` | `[softly] В три семнадцать ночи в моей квартире зазвенела люстра. [dramatically] Через сорок секунд моего дома больше не было.` |
| Знакомство | `[warmly]` | `[warmly] Меня зовут Марк. Мне двадцать пять. Я чиню то, что сломалось.` |
| Нарастание угрозы | `[nervous]`, `[cautiously]` | `[nervous] Сначала погас свет в подъезде. Потом на улице.` |
| Удар, событие | `[breathless]`, `[gasps]` | `[gasps] Пол ушёл из-под ног.` |
| Страх, тишина | `[whispers]`, `[trembling voice]` | `[whispers] Я не дышал. Кто-то шёл по лестнице.` |
| Разрядка, шутка | `[chuckles]`, `[sarcastic]` | `[sarcastic] Отличный план. [chuckles] Других у меня не было.` |
| Потеря, грусть | `[sad]`, `[sighs]` | `[sighs] Я не успел.` |
| Выбор | `[pause]` до и после | `Направо — больница. Налево — школа. [long pause] Я пошёл налево.` |
| Клиффхэнгер | `[slowly]` + многоточие | `[slowly] А потом в подвале… кто-то постучал.` |
| Аутро | `[softly]` | `[softly] Я закрыл глаза. А когда открыл — это был уже другой мир.` |
| Реплика ребёнка | голос GIRL/BOY: префикс-тег + эмоция | `[childlike voice] [scared] Марк, а земля ещё будет качаться?` |

Правила:
- Тег действует до следующего тега, поэтому меняй его только там, где меняется эмоция, примерно раз в 2–4 фразы. Если тег стоит на каждой фразе, голос звучит истерично.
- Вне аудио-тегов квадратные скобки не используй. Служебные пометки сценария вроде `[ПАУЗА 1.2]` перед озвучкой замени на `[pause]` / `[long pause]`.
- Ударение в трудных словах: на v3/v4 замени слово на IPA между слэшами. Так же исправляй имена и топонимы, которые голос читает неверно.
- Числа можно оставить цифрами, v3/v4 читают их правильно. Если в пробе ошибка (например, «3:17» прочитано как «три двоеточие семнадцать»), перепиши словами.

## Озвучка реплик разными голосами
- В `script.md` каждая прямая речь размечена говорящим: `@F «…»` (женщина), `@G «…»` (девочка), `@B «…»` (мальчик); без метки — MALE. Рассказ всегда MALE.
- Текст главы режется на сегменты по смене голоса; MALE-сегменты рассказа идут кусками по главе, реплики FEMALE/GIRL/BOY — отдельными генерациями. В озвучку кавычки и слова «сказала она» остаются у рассказчика (MALE), сама реплика — голосом персонажа.
- Сегменты склеиваются по порядку с паузами 0,2–0,35 с вокруг реплики; тайминги слов каждого сегмента сдвигаются на его начало и сливаются в общий `words.json` с полем `"v": "MALE|FEMALE|GIRL|BOY"` (субтитры могут подсвечивать реплики цветом говорящего).

## Нарезка и сборка
- Озвучивай **по главам**, кусками ≤ 2 500 символов по границам абзацев. Все куски клади в один flow, чтобы голос и настройки совпадали.
- Каждый кусок прогоняй через `creative_transcribe_audio`, чтобы получить пословные тайминги, и сохраняй в `audio/chNN.words.json` формата `[{"w","s","e"}]`. Перед этим убери из текста теги: они не произносятся.
- Склейка глав: между абзацами внутри главы пауза 0,25–0,4 с, между главами 1,5–2 с (под затемнение). Получится `audio/voice.wav`, 48 кГц.
- Проверь темп: 138–145 слов/мин по каждой главе. Если глава выбивается, переозвучь только её и только с согласия пользователя, потому что это тратит кредиты.
- Повторную генерацию одного и того же куска «на всякий случай» не запускай: это двойное списание кредитов.

## Музыка и SFX тоже из ElevenLabs
- Музыка: `eleven_music_v2_5`, `instrumental`, по 1–3 трека на мир (до 600 с каждый), атмосферный эмбиент/синт под жанр. Плюс короткая «тема Марка» на 10–20 с, одна на канал, для крючка и аутро.
- SFX: `eleven_text_to_sound_v2`, 0,5–30 с, по таблице событий из сценария (звон люстры, гул, треск, сирена, шаги). Фоновые подложки делай с `loop: true`.
- Сведение: `scripts/mix_audio.py`. Голос не трогаем, музыку прижимаем под речью (ducking ~9 dB), SFX −6 dB, мастер −15 LUFS, true peak −1,5 dBTP.
