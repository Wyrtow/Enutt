# Анимация персонажей — стандарт качества «Один герой»

Персонаж не может быть «картонкой, которая едет по экрану». Каждый персонаж в кадре **жив всегда**: дышит, моргает,
смотрит, переносит вес. Каждое действие — с подготовкой, самим действием и доводкой. Урезанная анимация
(слайд фигуры без шагов, поза-рывок без переходов, застывший персонаж) — брак, QA и проверяющий её возвращают.

Эталон рига и сцены: `style_tests/anim/rig.js`, `style_tests/anim/scene.js`, ролик `style_tests/anim/mark_anim_test.mp4`.
В Remotion риг переносится как компонент `Mark` 1-в-1 (функции от кадра, без случайности).

## 1. Риг (скелет), а не картинка
- Суставы: таз → бёдра/колени/щиколотки (ноги — **двухзвенная IK**, стопа ставится в точку пола), плечи → локти → кисти (**FK**), шея → голова.
- Части: корпус (худи) деформируется от наклона и дыхания; шарф — цепочка из 4 точек с физикой; волосы — вторичное движение чёлки.
- Повороты: анфас (turn 0) ↔ три четверти (turn 0,85) плавно 12–18 кадров: корпус сужается, черты лица и ухо смещаются, дальние рука/нога уходят за корпус и темнеют.
- Лицо: глаза (размер, взгляд, моргание), брови (спокойно / тревога / злость), рот (линия → «о» при вздохе/крике), нос сдвигается при повороте, щетина.

## 2. Слои живости (всегда включены)
| Слой | Параметры |
|---|---|
| Дыхание | грудь/плечи 1–2 px, период 3,5 с; в страхе/после бега — 0,6–1 с |
| Перенос веса | таз ±4–6 px, период 4–5 с, только в покое |
| Моргание | раз в 2–5 с, 4–5 кадров (½ · закрыто · закрыто · ½); двойное — после испуга/удивления |
| Взгляд | саккады глаз каждые 1–3 с; **глаза ведут голову на 2–3 кадра** |
| Вторичное | шарф (физика), чёлка подпрыгивает от шагов/ударов |
| Контакт | тень под ногами всегда, растёт с шириной стойки; ноги не скользят по полу |
Никаких `Math.random()` в кадре — только детерминированные функции/предрасчёт с seed.

## 3. Принципы движения (обязательны для каждого действия)
- **Упреждение**: перед резким действием — движение в обратную сторону (присел перед прыжком, отклонился перед рывком) 3–6 кадров.
- **Тайминг и замедления**: ключи соединяются smootherstep; никаких линейных интерполяций поз.
- **Доводка и перекрытие (follow-through / overlap)**: после остановки корпус по инерции наклоняется вперёд и возвращается (2–3 колебания с затуханием); голова, руки, шарф догоняют корпус с запаздыванием 2–6 кадров.
- **Дуги**: кисти, голова и стопы движутся по дугам, не по прямым.
- **Сжатие/растяжение**: тонко, ≤ 3–5 % (вздрогнул, приземлился).
- **Ведущая часть**: поворот начинают глаза → голова → плечи → таз.
- **Поза читается силуэтом**: эмоция понятна даже по чёрной заливке.

## 4. Циклы
- **Шаг**: полный цикл ноги 1 с (2 шага/с), фазы ног сдвинуты на ½; опора — стопа неподвижна в мире, перенос — по дуге с подъёмом 25–35 px и отрывом носка; таз ниже в момент постановки стопы (боб 5–7 % роста); наклон вперёд 3–6°; руки в противофазе ногам ±20–25°, локоть сгибается сильнее на махе вперёд; голова с запаздыванием. Разгон и торможение 10–14 кадров, не мгновенно.
- **Бег**: 1,5–1,8 цикла/с, фаза полёта, наклон 10–15°, руки согнуты 80–100°, сильнее боб и шарф.
- **Испуг**: присел 3–4 кадра → вздрогнул вверх → оседание; руки — защитный жест к груди; брови вверх, рот «о», взгляд на угрозу; частое дыхание дальше по сцене.
- **Падение/толчок**: тело отстаёт от камеры, руки в стороны для баланса, шаг для восстановления.
- **Разговор** (если реплика в кадре): движение рта по словам `words.json` (открыт на гласных), кивки, жесты на ударных словах.

## 5. Библиотека поз и действий (пополняется роликом за роликом)
stand, breathe-idle, look-around, startle, protect, reach-up, point, walk, run, stop-settle, turn-front↔¾, crouch, crawl, climb, fall-recover, carry (ребёнка/предмет), sit, lie, hug, hold-hand (с ребёнком), phone-look, flashlight, push-door, pull-someone, exhausted, cry-quiet, relief-exhale, laugh-small.
Каждая — функция `(кадр, параметры) → поза рига` + тестовый клип 3–5 с в `production/remotion/tests/`.

## 6. Проверка анимации (перед полным рендером)
1. Клип 3–5 с на каждое новое действие + стоп-кадры каждые 4 кадра одним листом.
2. Ноги: стопы на опоре не скользят (координата x стопы постоянна ±2 px весь период опоры); колени не выгибаются назад; тень на месте.
3. Нет кадров-рывков (поза не «прыгает»), нет застывшего персонажа > 1 с.
4. Свежий агент-проверяющий оценивает «живость» и «качество движения» 0–10 по клипам; ниже 8 — переделка.
